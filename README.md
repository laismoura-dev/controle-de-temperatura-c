# controle-de-temperatura-c
# 🌡️ Controle de Temperatura em C

## 📌 Sobre o projeto

Este projeto foi desenvolvido durante meus estudos de Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de praticar lógica de programação utilizando a linguagem C.

O programa recebe uma temperatura informada pelo usuário e apresenta mensagens de acordo com as condições definidas no código.

## 🛠️ Conceitos praticados

- Linguagem C
- Estruturas condicionais (`if`, `else if` e `else`)
- Funções
- Entrada e saída de dados
- Lógica de programação

## ▶️ Como executar

1. Tenha um compilador C instalado, como o GCC.
2. Compile o arquivo:

   `gcc controledetemperatura.c -o controle`

3. Execute o programa gerado no seu sistema operacional.

## 🎯 Objetivo

Praticar os fundamentos da programação e desenvolver minhas habilidades para criar soluções utilizando código.
